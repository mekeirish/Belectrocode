Guide
À propos d'Electrocode
🔐
Token GitHub
Colle ton token PAT avec les scopes repo et workflow. Il est stocké uniquement dans ton navigateur.
📦
Dépôt cible
Choisis un dépôt GitHub. Electrocode va y injecter main.js, package.json et un workflow GitHub Actions.
⚡
Génération auto
Le workflow compile un .exe portable (Windows 32 bits) via Electron et electron-builder.
⬇️
Téléchargement
Une fois le build terminé, un lien de téléchargement direct est généré via nightly.link.
💡
Astuce
Le workflow se relance automatiquement à chaque push sur main ou master.
